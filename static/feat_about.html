API 网关管理控制台

API Gateway Admin Console · v0.0.1

本管理台用于集中管理 API 网关的令牌、渠道、用户、日志、消费统计与系统设置。 界面风格参考 new-api 管理控制台，全部为纯 HTML / CSS / JavaScript，无外部依赖，可离线使用。

功能概览

  • 令牌管理：创建 / 编辑 / 删除 / 批量生成令牌，设置额度、分组与模型范围。
  • 渠道管理：维护上游渠道，配置认证方式、模型映射、优先级与权重，支持在线测试。
  • 日志与统计：请求日志检索、消费统计、费用明细与渠道健康监控。
  • 用户与充值：用户管理、充值码生成与兑换、额度调整、团队与邀请。
  • 模型配置：模型价格倍率、分组倍率与模型别名。
  • 系统设置：站点信息、OAuth 安全、通知渠道、2FA 两步验证。
